# Canvas source

Editable source of the EkBill design canvas (one `.dc.html` per artboard, laid out by `canvas.json`).
These files need the design-canvas runtime (`support.js`) to render, so they are for re-importing into
the canvas, not for the app. For static, self-contained references use `../screens/`.

Narangi: Login, Main (home), NewBill, BillDone, Remind, GST, Profile, Tokens (kit)
Harmony: B_Welcome, B_Home, B_Customer, B_Remind, B_Palette (kit)
